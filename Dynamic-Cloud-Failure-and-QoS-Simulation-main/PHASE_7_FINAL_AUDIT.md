## 4. Discovered Issues & Corrections Applied

During the Phase 7 audit, the following mismatches and documentation defects were detected and resolved:

### 1. Test Suite Count Synchronization Across Documentation
- **Issue:** `README.md`, `docs/TESTING_REPORT.md`, `docs/FINAL_PROJECT_REPORT.md`, and `F_report.docx` originally cited 122 tests (or 111 non-UI tests). Following the implementation of Phase 9 (Persistent Storage & Audit History), 15 new test cases were added in `tests/test_persistence.py` and 2 monitoring tests were added, bringing the total suite to 138 tests.
- **Correction Applied:** Updated `README.md`, `docs/TESTING_REPORT.md`, `docs/FINAL_PROJECT_REPORT.md`, Chapter 6 paragraph 244, and Table 6.2 in `F_report.docx` to report the authoritative count: **138 tests passed out of 138 (100% pass rate in 20.07s)**.

### 2. List of Figures Inconsistency in `F_report.docx`
- **Issue:** In `F_report.docx` Chapter 5 body, both Fig. 5.5 (*Decision comparison between prior choice, newly selected service and benchmark*) and Fig. 5.6 (*Candidate service comparison and ranking table*) were present. However, Table 5 (LIST OF FIGURES) in the preliminary section omitted Fig. 5.6, listing only 12 figures.
- **Correction Applied:** Cloned the formatting of Table 5 row 7 and inserted Fig. 5.6 into Table 5, establishing 100% alignment between the preliminary List of Figures and the body figures.

### 3. College Template Footer Requirement
- **Issue:** In `F_report.docx`, `word/footer2.xml` contained only `PAGE \* MERGEFORMAT 2 | Page` without department or institutional attribution, violating the college template requirement: *"Footer: Dept. of AI&DS, SaIT 2026-27, with page number"*.
- **Correction Applied:** Reconstructed `word/footer2.xml` and `word/footer1.xml` with:
  - Left: `Dept. of AI&DS, SaIT 2026-27` in Times New Roman, 10 pt.
  - Right: Right-aligned tab stop at 9029 twips displaying `Page <PAGE>`.
  - Top border: Subtle 4-twip single border line separating footer from body text.

### 4. Header Position Outside Page Border
- **Issue:** In `F_report.docx`, `w:pgBorders` had `top w:space="0"`, which placed the top border line at the extreme paper edge, rendering the header inside the page border.
- **Correction Applied:** Configured `top w:space="31"` (the maximum allowed distance from paper edge) and header position `header="400"` twips (20 pt). The header text at 20 pt is placed cleanly above the 31 pt top border line, properly positioning the header outside the page border. Trailing empty paragraphs in `word/header2.xml` were also purged.

### 5. Premature Page Breaks in Appendices
- **Issue:** In `F_report.docx`, empty paragraphs containing hard `<w:br w:type="page"/>` elements preceded each of Appendices D through W. Because many appendices are short reference tables or code listings (0.5 to 1 page), this caused large blank white spaces at the bottom of almost every appendix page.
- **Correction Applied:** Removed the 20 unnecessary hard page breaks before Appendices D through W. Appendices now flow naturally across pages, eliminating unsightly blank spaces while strictly preserving all 23 appendices and their complete technical content.

### 6. Test Suite Isolation for Persistence Layer
- **Issue:** Interactive dashboard use persisted mutated service states (e.g., latency spikes) into `data/cloud_qos_simulation.db`. When headless UI tests in `test_ui_dashboard.py` ran, they loaded the persisted mutated state instead of baseline state, causing assertion mismatches.
- **Correction Applied:** Created `tests/conftest.py` with an autouse fixture `isolated_test_db` that points `CLOUD_QOS_DB_PATH` to a clean temporary SQLite database per test invocation. This guarantees complete test isolation, deterministic baseline execution, and zero cross-test state leakage.
